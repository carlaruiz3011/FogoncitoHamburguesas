# Fogoncito - Hamburguesería 🍔🔥

Proyecto de sitio web para la hamburguesería "Fogoncito", desarrollado como parte de la Ejercitación 3.1 (del diseño al código).

## Integrantes
* Carla Ruiz
* Maria Luz Valli
* Guadalupe Perez

## Descripción
El sitio permite visualizar el menú completo, las promociones del día, agregar productos a un carrito de compras y realizar un pedido con validación de datos de envío. Está diseñado con un estilo oscuro y colores de fuego, siguiendo el prototipo UX/UI original.

## Tecnologías utilizadas
* HTML5 (Semántico)
* CSS3 (Variables, Grid, Flexbox, Media Queries)
* JavaScript (Manipulación del DOM, LocalStorage, Validación de formularios)
